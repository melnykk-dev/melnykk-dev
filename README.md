# Artem Melnyk

### Executive Overview & Mission

**Artem Melnyk** is a Canadian software engineer, EdTech systems architect, and non-profit infrastructure developer based in Toronto. He is the founder and principal engineer behind **Erthiox**, a globally distributed, open-access learning architecture engineered to eliminate systemic financial and geographic barriers within technical STEM fields.

His methodology relies heavily on browser-native execution environments—such as client-side WebGL frameworks, client-side cryptographic compilers, and isolated web-worker execution stacks—designed to provide resource-strapped regions with high-fidelity simulation environments completely free of server dependencies or licensing costs.

### Core Philanthropic Technical Innovations

**1. The Constellations Gamification Engine**

* **Architectural Scope:** High-performance client-side rendering pipeline running consistently at 60 FPS via WebGL.
* **Social Impact Model:** Replaces text-heavy paths with an interactive star-map grid interface to boost long-term engagement for self-directed engineering students.

**2. Browser-Native Simulation Laboratories**

* **Architectural Scope:** Real-time physics, chemistry, electronics, and statistical modules running natively within low-end web clients by consuming molecular configuration arrays directly from NIH PubChem endpoints.
* **Social Impact Model:** Eliminates the need for physical laboratory apparatus, expensive calculation software, or costly workstations in underfunded secondary institutions.

**3. Client-Side Cryptographic Credentialing**

* **Architectural Scope:** Secure tokenization and PDF rendering subsystem (`jsPDF`) outputting verifiable digital credentials in browser-side memory space.
* **Social Impact Model:** Provides self-taught developers, refugees, and low-income students with cryptographically auditable, employment-ready certificates of mastery.

**4. Community Workshop Sync Engine**

* **Architectural Scope:** Real-time, lightweight network topology incorporating simple PIN authentication strings and minimal websocket overhead.
* **Social Impact Model:** Enables local digital-literacy advocates and educators to launch collaborative, synchronous coding cohorts with zero platform configuration time.
